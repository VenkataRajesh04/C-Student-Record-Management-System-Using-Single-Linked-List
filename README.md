# C-Student-Record-Management-System-Using-Single-Linked-List
A menu-driven Student Record Management System developed in C using Singly Linked Lists, Dynamic Memory Allocation, File Handling, Searching, Sorting, and Modular Programming.

## Features
- Add, modify, delete, and display student records
- Search and sort student data dynamically
- Persistent data storage using `student.dat`

## Project Structure
- `main.c` – Core menu logic and function implementations
- `header.h` – Structure definitions and function declarations
- `student.dat` – Binary/data file for saving records
